# Domain Modeling

Sharpen terms, boundaries and relationships while choices remain upstream. Load the full glossary; challenge overloads with concrete scenarios, check source and trace affected owners. Keep pending meaning labeled in topic Wiki. Write glossary changes only on explicit confirmation; offer ADR/DDR only when its criteria hold. This companion does not authorize implementation.
