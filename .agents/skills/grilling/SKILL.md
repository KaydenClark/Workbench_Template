# Grilling

Reuse [owner judgments](../implement/execution-authority.md): explicit confirmation before leaving Explore; explicit execution approval before leaving Prepare. Loading a skill or delegating grants neither.

Investigate and grill one decision at a time. Read back each answer and await explicit confirmation before advancing; corrections restart that step. Keep unresolved choices pending, retain reasons and consequences, and stop at the confirmed shared concept. Preserve/promote/specify/handoff/execute only through an authorized separate exit. Saved context is composed through `jot`.
