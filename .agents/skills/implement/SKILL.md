# Implement

Reuse [owner judgments](../implement/execution-authority.md): explicit confirmation before leaving Explore; explicit execution approval before leaving Prepare. Loading a skill or delegating grants neither.

Implement one eligible assigned Task with one writer. Resolve Spec/Task through the manifest, recover authority and claim only eligible work. Drive public-seam red/green, update existing owners and verify the exact candidate and remote recovery. Follow Task merge answers, assembled independent review and checked branch completion. Stop at the authorized endpoint; preserve failures and owner/main gates.
