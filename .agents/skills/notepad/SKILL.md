# Notepad

Use `jot` for ordinary fresh context. This compatibility skill reads and maintains preserved legacy JSON notes or domain adapters that still require their schema. Preserve revisions, access, sources, corrections and unresolved material. Read only the needed slice; reconcile before any authorized cleanup. It grants no private-to-tracked transfer, source deletion or new objective.
