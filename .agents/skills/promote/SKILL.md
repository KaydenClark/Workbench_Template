# Promote

Reuse [owner judgments](../implement/execution-authority.md): explicit confirmation before leaving Explore; explicit execution approval before leaving Prepare. Loading a skill or delegating grants neither.

Reconcile only selected supported claims whose authority and evidence already exist into their durable owners. Preserve sources, claim status, corrections, unresolved/private context and history; verify read-back. Call `save` only within the same publication authority. Promotion neither starts an interview nor grants implementation, Canon status or extra scope.
