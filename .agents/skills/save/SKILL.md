# Save

Reuse [owner judgments](../implement/execution-authority.md): explicit confirmation before leaving Explore; explicit execution approval before leaving Prepare. Loading a skill or delegating grants neither.

Persist already-authorized work in its existing owners. Call `jot` for unresolved context and `to-docs` for durable truth; preserve privacy, history and unrelated work. Verify changes, update source continuation, then follow authorized publication and workspace closeout. Prove freshly fetched remote containment; local bytes, a draft PR or optional transport are distinct boundaries and do not waive review or main approval.
