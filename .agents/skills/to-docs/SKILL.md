# To Docs

Route already-settled truth into existing documentation owners. State proposed destinations, preserve governing claims, evidence, rationale and proposals in their proper owners, and keep citations/source status intact. Do not reopen discovery, invent decisions or create another store. Record partial work honestly; publication and implementation retain their separate scope and gates.
