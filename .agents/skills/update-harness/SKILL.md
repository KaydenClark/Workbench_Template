# Update Harness

Reuse [owner judgments](../implement/execution-authority.md): explicit confirmation before leaving Explore; explicit execution approval before leaving Prepare. Loading a skill or delegating grants neither.

Reconcile an adopted room with the pinned canonical Workbench release while preserving project truth, work state, evidence and custom controls. Establish exact source and authority, inventory/baseline, choose the supported route, migrate, verify and prove remote recovery through the target workflow. Do not rerun Adoption or overwrite project-owned files.
