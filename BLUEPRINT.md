# Workbench Template - Blueprint

## What it is

The Workbench Template is a copyable reference installation of LLM Workbench. It gives a project a coherent starting structure and maintainers a real installed room for verifying explicit harness updates. Its plain files explain their ownership without imposing a fictional application.

## Who it serves

People starting projects need a legible foundation they can deliberately adapt to their own product. Arriving agents need clear authority, boundaries and routes to the right context. Harness maintainers need a reference whose installed behavior can be checked independently of the producer checkout.

## Promised outcomes

A reader can understand each control, lane and collection, find its owning source, and distinguish reusable structure from room-specific history. One local command explains the room; the optional tour follows the manifest rather than becoming another authority.

A copy remains understandable and adaptable to a named product. The reference carries no application data or secrets; tracked and ignored support state have clear owners. Updates preserve room identity, historical evidence, unfinished work and deliberate differences while exposing compatibility and unresolved acceptance honestly.

Maintainers can verify installed tools and ordinary workflows with receipts and recovery. Historical provenance, installed source identity, structural checks and actual behavior remain distinguishable. A successful update proves that update; fresh-project workflows and improved agent reliability require their own evidence. Independent review precedes integration, and main delivery remains owner-controlled.

[Supporting detail](workbench/wiki/MEMORY.md#template-direction-detail) preserves the architecture, lifecycle and verification boundaries behind this summary.

## Non-goals

This is not a fictional Example application, an autonomous portfolio manager, a replacement for upstream tool tests, or a tutorial for designing every product. Ordinary local work requires no paid service, private catalog, Foundry machinery or network access. The template does not publish itself, update unrelated rooms, import live personal context into copies or prove universal agent obedience.
