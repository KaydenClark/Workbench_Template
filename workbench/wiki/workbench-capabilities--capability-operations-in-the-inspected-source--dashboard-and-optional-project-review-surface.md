# Dashboard and optional project review surface

Use this section for dashboard and optional project review surface; [workbench-capabilities--capability-operations-in-the-inspected-source](workbench-capabilities--capability-operations-in-the-inspected-source.md) provides the surrounding context.

### Dashboard and optional project review surface

The producer Dashboard and the optional project Grill Board share a reviewed protocol but have different packaging. The producer's full five-section view is not installed by the generic managed-runtime update. The project component is a separate explicit deployment with its own receipt and empty local store.

Agents maintain questions, source routes and disposition receipts; only the owner answers through the page. Autosaved comments or ratings do not become approval. The Dashboard stores no parallel work truth, launches no agents and performs no owner publication or implementation. A missing complete draft is shown as unavailable rather than silently summarized into an approval.
