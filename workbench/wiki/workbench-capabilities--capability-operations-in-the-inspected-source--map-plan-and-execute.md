### Map, plan and execute

| Capability | What it does and why | Version evidence | Evidence |
|---|---|---|---|
| Standalone Task packets and receipts | Each `TASK.md` owns one executable slice. `convert-tasks` migrates unfinished legacy slices; `receipt` appends run proof, including exact candidate, Git state, checks, documentation and gaps. Packets traverse the acceptance, source and test owners rather than copying them, and chained receipts expose changed history. | Later development; standalone TASK.md first committed 2026-09-16, with packets and receipts on 2026-09-17 (first published version unestablished). | [source](https://github.com/KaydenClark/LLM_Workbench/blob/d4ff0fbcbed68af69082c4b71e70691510d8da0f/workbench/tools/task-packet.mjs); [checks](https://github.com/KaydenClark/LLM_Workbench/blob/d4ff0fbcbed68af69082c4b71e70691510d8da0f/tools/test-task-record.mjs); [standalone Task record](https://github.com/KaydenClark/LLM_Workbench/commit/cf6eeb12412dbb425fc14651f42987c5dafb3f2b); [Task packet](https://github.com/KaydenClark/LLM_Workbench/commit/08a0776548de227fbf0b2b46ef60bba557fbb954); [Task receipt](https://github.com/KaydenClark/LLM_Workbench/commit/afc2a188fa54c5ff4b9e2ccab33e63306231d40a) |

| Current hot Taskboard and retained Spec catalog | `render` updates the generated Markdown Taskboard and Spec catalog from their owning records.
