The current JSON board is a preview, not the default `TASKBOARD.json` destination. The Tracker still uses its earlier eight step names; newer workflow vocabulary did not rename runtime states. Full GitHub Issue graphs, trusted assignments, live transitions, Projects composition and claim-authority cutover remain separate delivery work. The existing Git claim route is not replaced by the read-only binding inspector.

Jot and handoffs preserve source-linked context; capture supplies neither permission nor implementation proof. Shared Jot pages require checked publication before another room can rely on integration availability. Explicit private capture and legacy JSON records retain their access boundary. Optional private session transport remains separately configured; ordinary Jot publication does not transfer a private source into tracked Git. Source tests establish tested behavior, not universal agent reliability or every downstream installation.


Lane Sweep is read-only: it never fetches, deletes, checks out, merges, pushes or runs the cleanup/Jot commands it suggests. Remote-tracking facts are only as fresh as the last fetch; missing GitHub access limits PR coverage while retaining branch/worktree reporting. It is not a gate on next, claim or close. `record-landing` proves containment against the named local remote-tracking revision; fresh fetch and subsequent record publication/readback remain caller responsibilities. The startup view grants neither assignment nor authority.
