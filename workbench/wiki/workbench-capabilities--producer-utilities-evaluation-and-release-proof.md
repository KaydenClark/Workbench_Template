# Producer utilities, evaluation and release proof

Use this section for producer utilities, evaluation and release proof; [workbench-capabilities](workbench-capabilities.md) provides the surrounding context.

## Producer utilities, evaluation and release proof

These tools belong to LLM_Workbench's producer repository unless an entry explicitly names an installed runtime. They make the harness inspectable and maintainable; they do not add a requirement for an ordinary project to run all producer machinery.

Static scores, passing fixtures and schema checks do not prove improved agent outcomes. Outcome claims require repeated controlled trials and stated limitations. The machine self-drift receipt explicitly requires semantic freshness review. Reference Template installation and owner main promotion are separate release facts. Context packing and research scaffolding create inputs and structure, not conclusions. The optional socket utility does not make Foundry, a recall database or any external scheduler a dependency of a portable Workbench.
